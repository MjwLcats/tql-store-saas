# 微信式 tabBar 设计

## 目标

底部导航调整为“首页、任务、应用、我的”，采用接近微信的克制全宽布局：白色底栏、顶部细分隔线、无悬浮胶囊和大阴影。现有胶囊模板、位移逻辑与样式以注释保留，后续可快速恢复。

## 纯文字交互

四个入口改为小红书式纯文字导航，不渲染图标、下划线或选中圆点。未选中文字使用 `#666A72` 和常规字重，选中使用主题色 `#165DFF` 和 600 字重；按压时只做短暂透明度与缩放反馈。原 SVG 图标资源继续保留，便于后续比较或恢复。

底栏固定在安全区上方并覆盖全宽，内容区高度保持 96rpx，标签字号提升为 28rpx，安全区单独追加，不参与内容区高度。内容页保留底部留白以避免最后一屏被导航遮挡。导航仍由父页面维护唯一 `activeTab`，本次只改变视觉表现，不重新引入页面路由。

## 验证

- 四个标签及页面标题顺序一致。
- 页面中不渲染任何 tabBar 图标。
- 点击切换时选中文字颜色和字重同步变化。
- 胶囊代码存在于注释中但不参与渲染。
- 390×844 移动视口无圆角胶囊、遮挡或安全区问题。
